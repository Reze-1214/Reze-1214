# Hola! 👋

Saya seorang **Web Developer** dan **Linux Desktop Enthusiast (Ricer)**. Saya suka merancang antarmuka website yang ringan, bersih, dan responsif—sekaligus menghabiskan waktu di dalam terminal untuk mengoprek tampilan desktop **Hyprland**, meracik *custom shell/widgets*, dan merapikan *dotfiles*. Bagi saya, UI/UX yang enak dipandang tidak hanya berlaku di *browser*, tapi juga di layar sistem operasi sendiri.

---

### 🚀 Tentang Saya
- 🖥️ Sedang seru-serunya membangun *custom desktop shell* dan konfigurasi **Hyprland (Wayland)** menggunakan **Quickshell (QML & JS)**.
- 🌐 Aktif membuat proyek *landing page*, komponen web yang ringan, dan aplikasi web interaktif.
- 📦 Lebih suka struktur kode yang *clean*, cepat, dan *to-the-point* tanpa *boilerplate* yang berlebihan.
- 🐧 Sehari-hari berdomisili di `~/.config` di atas **CachyOS Linux**.
